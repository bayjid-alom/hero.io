## 📱 HERO.IO

**HERO.IO** is a modern app discovery platform where users can explore popular mobile applications, view detailed app information, check ratings and reviews, and discover apps based on their interests. The platform provides a clean browsing experience with app statistics, rating insights, and installation management.

**Live Website |** [HERO.IO](https://hero-io-space.surge.sh/)




---

### 📝 Project Overview

HERO.IO is an app discovery and management platform designed to help users explore and manage mobile applications in one place. Users can browse a collection of apps, view detailed information, analyze ratings and download statistics, and manage their installed applications.

The application offers an interactive experience with dynamic app listings, search functionality, sorting options, data visualization, and a responsive user interface.

Built with **React and modern frontend technologies**, the project demonstrates practical implementation of component-based architecture, state management, client-side routing, data handling, and interactive UI development.

---




### ✨ Core Functionalities

- **Explore Apps** — Browse a collection of popular mobile applications.
- **App Details** — View detailed information about individual applications.
- **Search Apps** — Find applications using their names.
- **Smart Sorting** — Organize apps based on ratings, downloads, and other criteria.
- **Rating Insights** — Visualize user ratings through interactive charts.
- **Installation Management** — Install and manage selected applications.
- **Duplicate Validation** — Prevent duplicate app installations.
- **Installation Statistics** — Display app size, downloads, reviews, and average ratings.
- **Persistent Storage** — Maintain installation data using browser localStorage.
- **Interactive Navigation** — Navigate between Home, Apps, and Installation pages.
- **Responsive Interface** — Enjoy a consistent experience across mobile, tablet, and desktop devices.

### 🔌 Data Integration

The project uses a local JSON file to store application information, including app names, images, descriptions, company names, sizes, reviews, average ratings, downloads, and rating statistics.

Data is retrieved using JavaScript's `fetch()` and handled with **Promises, async/await, React's `use()`, and Suspense** to display applications dynamically.

---



### 📊 Data Visualization

The application uses **Recharts** to present application rating statistics through interactive charts.

- **Rating Distribution** — Display the distribution of 1-star to 5-star reviews.
- **Dynamic Chart Data** — Generate chart information directly from application data.
- **Visual Insights** — Help users understand application ratings more easily.
